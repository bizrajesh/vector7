# Projects
A project follows: **Draft → Init → Go / No-Go → In Progress → Ready to Launch → Launched** (No-Go closes it).

**Create a project:** Projects → **New project**. Enter the approval type (Village / Town / City), location and district (used to pick the SRO), survey and patta numbers, size in acres, guideline and market rates. Values are calculated for you (1 acre = 43,560 sq ft).

Then:
1. **Estimate** — pick stages, sub-tasks and facilities for a tier. See *Estimate & budget*.
2. **Go / No-Go** — record the decision. No-Go closes the project (read-only).
3. **Start** — choose the start date; stages and sub-tasks get planned dates in working days.
4. **Track** — update sub-tasks until every approval stage is done, then **Mark Ready to Launch**.
5. **Launch** — upload the layout picture, load the plots and go live.

Already have an approved layout? Use **Quick launch layout** instead — no estimate or tracking needed.
