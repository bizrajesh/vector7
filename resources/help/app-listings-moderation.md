# Listings moderation
- **Listings** — every listing on the marketplace. **Hide** one with a reason (emailed to the promoter) or **Restore** it. **Feature** listings for the home page.
- **Buyer reports** — “Report this listing” submissions (wrong price, already sold, fake, other). Mark resolved or dismiss.
- **Featured layouts** — pick the layouts shown in the home-page carousel.
- **Testimonials** — only approved, real testimonials appear on the home page.
