# Refunds
If a customer misses the sale completion window and asks for a refund, open the sale → **Request refund**. vector7 calculates **refund = paid − penalty** from your refund penalty table (Settings). A Tenant Admin approves or rejects it with their password; an approved refund is recorded as an expense, the plot returns to Available and a refund note is printed.
