# AI settings
Settings → **AI**: the Anthropic API key, default model and monthly cap, and for **Marketplace AI search**, **Marketplace chatbot** and **Workspace chatbot** separately: on/off, a daily cap and an optional model (a cheaper model is fine for search). Set the chatbot's **name**, **greeting** and the **FAQ** it may use.

Marketplace search and the marketplace chatbot are charged to the App's budget; the workspace chatbot and AI drafting use each tenant's monthly AI credits. When a feature is off or over its cap, search falls back to normal keyword and filter search.
