# Launch & plots
**Launch & plots** lists projects that are Ready to Launch and those already launched.

**Who:** Tenant Admin and Manager launch, upload the layout, import or edit plots and set prices or offers. Sales and Support see everything read-only.

1. Upload the **layout picture** (image or PDF).
2. **Load plots** — upload CSV / Excel, paste CSV, or **Extract** from a DXF, PDF or photo of the approved layout (check the extracted grid before importing). Required columns: plot_no, patta_number, size_sqft, facing, rate_per_sqft, status. Optional: dimensions, boundaries, road width, corner plot, offer, offer_rate_per_sqft and offer_valid_till (DD-MM-YYYY).
3. Fix every error shown row by row — nothing is imported until all rows are valid.
4. Add **promotion text**, **marketplace details** (approval badge, map pin, features, contact) and **photos**.
5. **Go live**. Place plot **pins** on the layout so buyers can tap plots on the map.

Re-importing updates plots with the same plot number. An offer shows only while today ≤ *offer valid till*; afterwards the actual price shows again.
