# Registration
1. **Registration** lists plots that are ROR. Choose **Init registration**.
2. Fill the checklist, registration date (the SRO is picked from the project's district), seller and buyer details (PAN is stored encrypted and shown masked), plot details and two witnesses. The buyer accepts the registration disclaimer.
3. Print the **registration pack**, attach the documents and **Submit** → ROR-Init.
4. After registration enter the document number and date → ROR-Completed; print the acknowledgement.
5. Enter the physical file number → **Sold**. The plot leaves the marketplace.
